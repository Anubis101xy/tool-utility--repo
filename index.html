Tool Utility Repo

Kodi repository for TorUtilityBox and friends.

Install the repository
  1. Kodi: Settings > File manager > Add source > https://anubis101xy.github.io/tool-utility--repo/
  2. Add-ons > Install from zip file > pick that source > repository.toolutility-1.0.0.zip
  3. Add-ons > Install from repository > Tool Utility Repo
